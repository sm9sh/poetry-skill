# HOWTO: Практичний посібник з використання екосистеми (v3.0.0)

Цей посібник описує 5 робочих процесів для написання поезії, створення промптів для **Suno AI**, **Udio AI** та **Flow Music**, а також запуску автоматизованих E2E-тестів.

Уся робота здійснюється через агенти в каталозі `.agents/skills/` (а не в кореневих файлах-дзеркалах).

Швидкий довідник: **10 AI Quality Gates** забезпечують контроль на кожному етапі — від генерації тексту до DAW-міксу.

---

## 1. Робочий процес 1: Написання автентичного вірша
1. Використовуй поетичних агентів з `.agents/skills/`.
2. Звертай увагу на рухомі наголоси, перехресне римування та використання одного з 6 регістрів.
3. Проходь перевірку на антишароварщину.

---

## 2. Робочий процес 2: Створення промпту для Suno AI
Для Suno використовуються два методи:
- **Method 1 (Conversational Paragraph)**: Описовий підхід.
- **Method 2 (HookGenius Tag Matrix)**: Структурований підхід з токен-економікою (80-180 символів).

Застосовуй суворі правила **Metatag Grammar**:
- Квадратні дужки `[]` для структури треку (`[Verse]`, `[Chorus]`).
- Круглі дужки `()` для бек-вокалу.
- 9 канонічних інлайн вокальних жестів (напр. *sigh*, *whisper*).

---

## 3. Робочий процес 3: Створення промпту для Udio v4
- **Формула**: Максимум 250 символів.
- **Оптимізація**: Context Length оптимізація.
- Використовуй Inpainting (*stars* `***`) для точкової корекції.

---

## 4. Робочий процес 4: Створення промпту для Flow Music Lyria 3.5
- Використовуй **Conversational agent mode**.
- Промпти формуються у вигляді діалогу з AI-асистентом для створення плавних музичних переходів.

---

## 5. Робочий процес 5: Post-Production (DAW та Мастеринг)
Після генерації треку на будь-якій платформі дотримуйся **DAW stem mixing checklist**:
1. Split Bass (розділення басу).
2. Tchad Blake distortion для сатурації.
3. Mid-Side reverb sidechain для вокалу.

Для мастерингу: уникай True Peak пастки (-1 dBTP для -6..-8 LUFS).

---

```powershell
# Повний запуск усіх тестів (Tiers 1–4)
py -3 tests/run_tests.py --all
```
