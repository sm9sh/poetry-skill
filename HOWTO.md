# HOWTO

## 1. Вірш
Попросіть вірш звичайними словами: тема, настрій, за бажанням форма («сонет», «верлібр», «коломийка»). Скіл `ukrainian-poetry` поверне лише вірш, без коментарів, якщо ви не попросите розбору.

Для «виробничої» якості або 100-бальної оцінки скіл використовує агентів з `skills/ukrainian-poetry/agents/`: кілька чернеток → зауваження критиків → одна фінальна редакція.

## 2. Пісня для Suno v6-mini
1. Дайте вірш (або тему) і жанр / настрій.
2. Скіл `ukrainian-poetry-to-suno` адаптує текст під пісню (див. `references/poem-to-song-adaptation.md`) і видасть три блоки: **Style**, **Exclude**, **Lyrics**.
3. У Suno: Custom mode → вставте блоки → **Variety = Off** (інакше Suno переписує ваш Style).
4. Неправильний наголос чи рядок виправляйте редагуванням секції, а не перегенерацією всієї пісні.

Правило дужок: усе в `(круглих)` Suno **співає**. Вказівки (`[Whispered]`, `[Key Change]`, `[Half-time feel]`) — лише в `[квадратних]`.

## 3. Пісня для Google Flow Music
Той самий процес, але замість Style — промпт природною мовою (2–4 речення) і компактніша структура (треки до ~3 хв). Проблемні секції — через Replace.
