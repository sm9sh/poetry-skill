# Suno Prompt Packs Index

Каталог із 7-ми спеціалізованих наборів промптів для `Suno AI Custom Mode` (v3.5 / v4).

Усі шаблони оптимізовані під бюджет **80–180 символів** (оптимально 80–150 символів) із нульовим витоком метаданих та англомовними дескрипторами стилю.

## 2. Як користуватися

1. **Обери пак** відповідно до бажаного настрою, тембру вокалу чи жанру.
2. **Скопіюй `Style of music`** — він уже збалансований за довжиною (80–180 символів) і ліво-правим пріоритетом.
3. **Встав український текст у `Lyrics`** та розміти секції квадратними метатегами (`[Intro]`, `[Verse]`, `[Chorus]`, `[Outro]`) та круглими дужками для бек-вокалу `(луна)`.
4. **Скопіюй `Exclude` вектор**, щоб захистити генерацію від металевого бруду, гудіння суб-басу та шароварщини.
