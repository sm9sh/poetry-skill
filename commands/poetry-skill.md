# /poetry-skill

Unified entry point for Ukrainian poetry and AI songs.

1. Take the brief from `$ARGUMENTS`.
2. **Poem only** → follow `skills/ukrainian-poetry/SKILL.md`.
3. **Song** (Suno / Flow Music / "зроби пісню") → if there is no text yet, write it with `skills/ukrainian-poetry/SKILL.md` in song form; then follow `skills/ukrainian-poetry-to-suno/SKILL.md` (adaptation, markup, stress, Style / Exclude, `scripts/check_lyrics.py`).
