# Suno Ukrainian Prompt Pack (Custom Mode Ready)

Готовий каталог із 10-ти високоточних конфігурацій `Suno AI Custom Mode` (v3.5 / v4) для сучасної української музики.

> **⚠️ Принцип подолання парадоксу локалізації**:  
> Поле `Style of music` формується англійськими дескрипторами (з точними назвами українських автентичних інструментів: `bandura`, `sopilka`, `tsymbaly`, `duda`), оскільки музичний енкодер Suno оптимізований під англійську термінологію.  
> Текст пісні, структура та бек-вокал у полі `Lyrics` пишуться виключно українською мовою.
