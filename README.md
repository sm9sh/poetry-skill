# Ukrainian Poetry & Suno AI Skill Ecosystem (v2.0.0)

Комплексна екосистема для генерації, аудиту, верифікації та перетворення автентичної української поезії у продакшн-промпти для генерації музики в **Suno AI** (v3.5 / v4).

---

## 1. Архітектура системи

Система побудована на двох взаємодіючих AI-скілах та спільному рівні канонічних довідників, 100-бальних рубрик і 4-рівневого автоматизованого E2E-тестування:

```text
                  [Вхідні дані / Бриф / Тема]
                                │
                                ▼
               ┌─────────────────────────────────┐
               │     ukrainian-poetry Skill      │
               │  - Силабо-тоніка та дольник     │
               │  - 14-складова коломийка        │
               │  - Рухомий наголос і омографи   │
               │  - Різнорідні міжчастиномовні   │
               │  - 6 регістрів і антишароварщ.  │
               └────────────────┬────────────────┘
                                │ (Структурований вірш + метатеги)
                                ▼
               ┌─────────────────────────────────┐
               │   ukrainian-poetry-to-suno      │
               │  - Токен-бюджет (80–180 симв.)  │
               │  - Метатеги [Verse]/[Chorus]    │
               │  - 8 сучасних жанрів UA музики  │
               │  - Акустичний Exclude-вектор    │
               └────────────────┬────────────────┘
                                │
                                ▼
                   [Suno AI Custom Mode Ready]
```

## 3. Ключові можливості

### 3.1 Українське віршування та лінгвістика
- **5 Силабо-тонічних розмірів**: Ямб (`U —`), Хорей (`— U`), Дактиль (`— U U`), Амфібрахій (`U — U`), Анапест (`U U —`) із підтримкою пірихіїв.
- **Несилабо-тонічні системи**: Дольник (інтервали 1–2 склади), Тактовик (1–3 склади), чисто тонічний вірш, 14-складова Коломийка `(4+4)+6` із цезурою після 8-го складу.
- **Білий вірш vs Верлібр**: Чітке розмежування неримованого метричного ямба та вільного синтагматичного верлібру.
- **Тверді форми**: Сонет (італійський та шекспірівський з обов'язковою вольтою на 9-му рядку), Рондо, Тріолет, Терцини.
- **Рухомий наголос та омографи**: Дотримання української норми (*вИпадок*, *чорнОзем*, *новИй*, *одИннадцять*), розрізнення омографів (*зАмок/замОк*, *дорогА/дорОга*).
- **Різнорідне римування**: Сувора заборона дієслівних рим та зменшувальних суфіксів; обов'язкові міжчастиномовні співзвуччя.
- **6 Автентичних регістрів**: Сучасний урбаністичний, камерно-інтимний, філософсько-неокласичний, козацьке бароко XVII ст., автентичний фольк, дитячий.
- **Антишароварщина**: Повна заборона бутафорського кітчу та сувенірних штампів.

### 3.2 Генерація музичних промптів Suno AI
- **Токен-економіка (80–180 символів)**: Оптимальний діапазон для усунення розмиття уваги моделі та уникнення дефолтного поп-рок усереднення.
- **Чистота полів**: Повна заборона витоку метаданих (`Language:`, `Theme:`) у полі стилю; виключно англійські музичні терміни з культурними звуковими якорями (`bandura`, `sopilka`, `white voice`).
- **Метатеги та бек-вокал**: Стандартизований синтаксис `[Intro]`, `[Verse]`, `[Pre-Chorus]`, `[Chorus]`, `[Drop]`, `[Outro]` та дужки `(...)` для підспівок.
- **8 Сучасних українських жанрів**: Ethno-Chaos, Post-Punk, Dark Synth, Trap-Folk, Melodic Metalcore, Shoegaze, Ethno-Rock, Neoclassical Bandura.
- **Автентичні вокальні тембри**: Білий голос (*white voice*), інтимний шепіт, пост-панк баритон, мелодекламація, екстремальний гроул/клін, автотюн-треп.
- **Акустичний Exclude-вектор**: Подавлення металевого дзвону, брудного басу, розмитого ревербератора та цифрових артефактів.

## 4. Швидкий старт

### Запуск E2E тестів
```powershell
# Запустити всі 59 тестів
py -3 tests/run_tests.py --all

# Запустити конкретний рівень (наприклад, Tier 1 або Tier 3)
py -3 tests/run_tests.py --tier 1
```

### Генерація пісні (Custom Mode)
1. Склади вірш за допомогою `skills/ukrainian-poetry/`.
2. Перетвори його у Suno-формат за допомогою `skills/ukrainian-poetry-to-suno/`.
3. Встав згенерований `Style of Music` (80–180 симв.), `Lyrics` (з метатегами) та `Exclude` у Suno AI Custom Mode.
