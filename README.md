# Ukrainian Poetry & Multi-Platform AI Music Generation Ecosystem (v3.0.0)

Комплексна екосистема для генерації, аудиту, верифікації та перетворення автентичної української поезії у продакшн-промпти для генерації музики на платформах **Suno AI v4.5/v5.5**, **Udio AI v4** та **Google Flow Music Lyria 3.5**.

Єдиним джерелом правди для системної архітектури є `AGENTS.md`.

---

## 1. Архітектура системи (6-Step Production Lifecycle)

Система побудована на 6-кроковому життєвому циклі продакшену, взаємодіючих AI-скілах та спільному рівні канонічних довідників:

```text
                  [Вхідні дані / Бриф / Тема]
                                │
                                ▼
               ┌─────────────────────────────────┐
               │     ukrainian-poetry Skill      │
               │  - Силабо-тоніка та дольник     │
               │  - Рухомий наголос і омографи   │
               │  - 5 поетичних субагентів       │
               └────────────────┬────────────────┘
                                │ (Структурований вірш + метатеги)
                                ▼
               ┌─────────────────────────────────┐
               │   Music Prompting Engine        │
               │  - 4 музичних субагенти         │
               │  - 8-Genre Western Anchor       │
               │  - Vocal Triple-Stack           │
               └────┬───────────┬───────────┬────┘
                    │           │           │
                    ▼           ▼           ▼
             [Suno AI]      [Udio AI]  [Flow Music]
```

## 2. Структура репозиторію

### 2.1 Канонічні скіли (Runtime-Ready у `.agents/skills/`)
Основні агенти та промпти розташовані у `.agents/skills/`.
- **5 поетичних субагентів** для генерації та аудиту текстів.
- **4 нових музичних субагенти** для Suno, Udio та Flow Music.

### 2.2 Автоматизована тестова інфраструктура
- Мастер-тестраннер охоплює Tiers 1-4.
- **Udio + Flow Music валідатори** для перевірки якості промптів.
- Валідація метрики, стилю, метатегів.

---

## 3. Ключові можливості та 10 AI Quality Gates

Система впроваджує матрицю з **10 AI Quality Gates** для наскрізного контролю якості.

### 3.1 Музичний Продакшн та AI Conductor
- **Western Genre Anchor**: Оновлена 8-жанрова таксономія.
- **Vocal Triple-Stack**: Формула для складних вокальних аранжувань.
- **AI Conductor extensions roadmap**: Послідовність генерації (Seed → Extend → Breakdown → Mega-Chorus → Outro).
- **Метатеги**: Суворе правило дужок (квадратні `[]` проти круглих `()`) та 9 канонічних інлайн вокальних жестів.

### 3.2 Post-Production та Дистрибуція
- **DAW stem mixing checklist**: Split Bass, Tchad Blake distortion, Mid-Side reverb sidechain.
- **Мастеринг**: Запобігання True Peak пастці (-1 dBTP для -6..-8 LUFS).
- **Стримінгова дистрибуція**: Пороги Skip Rate, усунення Playlist Placement Trap.

## 4. Швидкий старт

### Генерація поезії та мультиплатформного промпту
1. Склади вірш за допомогою `skills/ukrainian-poetry/`.
